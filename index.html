How it works

Record once, replay anywhere

The algorithms never touch the screen. They run to completion first, and the page plays back what they did.

01 · Record

Run against a tracer

Each algorithm sorts a copy of the array through a tracer that logs every compare, swap and write, plus the pseudocode line it came from.

{ t: 's', i: 4, j: 5, l: 6 }
02 · Replay

Draw from the log

The canvas replays the log at whatever speed you pick. Because the log is fixed, playback runs forwards or backwards equally well.

03 · Checkpoint

Jump without waiting

A snapshot is stored every 512 operations, so any point on the timeline is at most 512 replays away. Bubble sort on 256 bars is about 50,000 operations and still scrubs instantly.
